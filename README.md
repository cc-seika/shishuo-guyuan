# 师说古渊小程序首版

当前版本完成了登录、双路线导览与“我的”页面交互闭环：扫码打开登录页，勾选用户协议后点击“微信一键登录”进入首页；点击首页底部“导览”进入文化研学线，再点击“休闲体验线”切换对应导览页；点击首页底部“我的”进入个人中心，并可从底部菜单返回首页或导览页。

界面基准画布已按参考图统一为 `591 × 1280 px`。H5 与微信小程序会在保持该比例的基础上适配实际手机屏幕。

移动端使用可视窗口自适应：根据 iPhone Safari 或微信内置浏览器实际剩余高度完整等比缩放页面，并避开刘海、灵动岛和底部安全区。页面不会再通过裁切来铺满屏幕；较矮的机型会在左右保留少量背景，以保证整张界面完整可见。

## 目录

- `web`：可直接在手机浏览器或微信内扫码预览的 H5 原型。
- `wechat-miniprogram`：可导入微信开发者工具的原生小程序工程。

在项目根目录运行：

```powershell

```

本机调试地址为：

```text
http://127.0.0.1:4173/web/?v=flow-6#login
```

本机调试链接仅用于开发；对外分享请使用上方 GitHub Pages 公网地址和二维码。

## 微信小程序预览

1. 打开微信开发者工具，导入 `wechat-miniprogram` 目录。
2. 首次设计校对可使用测试号；需要真机二维码时，将 `project.config.json` 中的 `touristappid` 替换为团队的小程序 AppID。
3. 点击开发者工具中的“预览”，由微信生成当次体验二维码。
4. 正式上线前需要在微信公众平台完成上传、体验版测试、审核与发布；发布后再配置正式小程序码。

## 首版边界

- 当前页面以已确认的登录、首页、双路线导览与“我的”视觉稿为高保真底图，适合先验证页面跳转、信息密度和点击路径。
- 休闲体验线、亲子探索线与实时定位导航已设置明确的“下一版接入”反馈，没有伪装为已完成能力。
- 下一轮如果要调整具体文案、卡片、地图节点或适配不同屏幕，应把对应区域逐步拆成原生组件，而不是继续修改整张底图。
